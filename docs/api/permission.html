Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
GET /organizations/{organization_id}/permissions/{user_id} load Get a user's permissions
PUT /organizations/{organization_id}/permissions/{user_id} update Update a user's role permissions. Payload should contain a mapping of pages to a set of the desired roles, if the page has Role Based Access Control. Otherwise, the pages should map to an empty hash. User will lose access to any pages omitted from the payload
